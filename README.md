# GitStore organization profile

The public [GitStore organization profile](https://github.com/gitstore-dev) is published from `profile/README.md`.

Approved branding assets live in `assets/branding/`. The profile splash switches between light and dark variants using a `<picture>` element. `avatar.png` is the organization avatar, with a solid background for both GitHub themes; upload it through the organization profile settings when updating the avatar.

Website: [gitstore.dev](https://gitstore.dev) · Product: [GitStore](https://github.com/gitstore-dev/GitStore)
