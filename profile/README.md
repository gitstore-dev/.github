### Your catalog. With an undo button.

GitStore helps commerce teams prepare catalog changes, review them before publishing, and keep a way back when something goes wrong.

- **Prepare campaigns together.** Work on seasonal launches without mixing them into the live catalog.
- **Review changes with confidence.** Check supplier updates and AI-written content before they reach customers.
- **Keep a clear history.** See what changed and recover from mistakes.

For developers, GitStore brings Git branches, diffs, and reversible commits to catalog operations. Products, variants, categories, and collections live in Markdown files with YAML frontmatter; descriptions are the Markdown body. GraphQL exposes the admitted catalog state to applications.

**Open source, currently in alpha.** APIs and architecture are still evolving.
